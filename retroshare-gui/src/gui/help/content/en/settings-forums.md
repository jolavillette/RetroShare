# Forums

This page of the preferences holds the options of the [Forums](forums.md)
page: how a message is displayed when you select it, and how forums are
opened.

Every change is applied at once. The display options are used the next time a
message is shown: select the message again to see the effect.

## Layout

The page has two groups: **Misc** at the top and **Tabs** below.

## Buttons

### Misc

- **Load emoticons (costly)**: when checked, the smiley codes of a forum
  message are drawn as pictures. Off by default: the conversion is slow on long
  messages. If long posts take a while to appear after you enable it, disable
  it again.
- **Set message to read on activate**: when checked, a message is marked as
  read as soon as you select it in the list of threads. When unchecked, a
  message stays unread until you mark it yourself. On by default.
- **Expand new messages**: on by default. This option is saved, but the current
  forum page does not use it.
- **Load embedded images**: when checked, the pictures embedded in a forum
  message are shown as soon as the message is displayed. When unchecked, the
  pictures are not shown with the message. Off by default.
- **Minimum font size**: the smallest size, from 1 to 64, allowed for the text
  of a forum message. Text that the author wrote in a smaller size is enlarged
  to this size. 10 by default.
- **Minimum text contrast**: the lowest contrast allowed between the text of a
  message and the background of the reading area, from 1.0 to 21.0 in steps of
  0.5. Text whose colour is too close to the background is recoloured so that
  it stays readable, for instance a dark text read with a dark style sheet.
  4.5 by default; 1.0 leaves the colours of the author untouched.

### Tabs

- **Open each forum in a new tab**: when checked, every forum you select in the
  list opens in its own tab, and the tabs stay open until you close them. When
  unchecked, the Forums page shows one forum at a time: selecting another
  forum replaces the one on screen, and the extra tabs that were open are
  closed. Off by default. Whatever the choice, the entry **Open in new tab** of
  the context menu of the forum list still opens a forum in an additional tab.
- **Hide tabbar with one open tab**: when checked, the bar that holds the tabs
  is hidden as long as only one forum is open. On by default.
