# Channels

This page of the preferences holds the options of the
[Channels](channels.md) page: how channels are opened, whether smileys are
drawn in channel descriptions, and the size limit of automatic downloads.

Every change is applied at once.

## Layout

The page has three groups, from top to bottom: **General**, **Tabs** and
**Downloads**.

## Buttons

### General

- **Load Emoticons**: when checked, the smiley codes found in the description
  of a channel are drawn as pictures. When unchecked, the description is shown
  as plain text with its links. On by default. The same option is used for the
  description of a board.

### Tabs

- **Open each channel in a new tab**: when checked, every channel you select in
  the list opens in its own tab, and the tabs stay open until you close them.
  When unchecked, the Channels page shows one channel at a time: selecting
  another channel replaces the one on screen, and the extra tabs that were
  open are closed. Off by default. Whatever the choice, the entry
  **Open in new tab** of the context menu of the channel list still opens a
  channel in an additional tab.
- **Hide tabbar with one open tab**: when checked, the bar that holds the tabs
  is hidden as long as only one channel is open. On by default.

### Downloads

- **Maximum Auto Download Size (in GBs)**: the size limit, in gigabytes, of the
  files that RetroShare downloads by itself from the channels where automatic
  download is enabled. A file whose size reaches the limit is not downloaded
  automatically; you can still download it by hand from the post. The value
  goes from 1 to 200 and is 8 by default. The limit is kept by your node, not
  by the interface: it also applies when the node is driven by another client.

## How to

### Keep several channels open side by side

1. Check **Open each channel in a new tab**.
2. Go to the [Channels](channels.md) page and click the channels you want to
   read: each one gets its own tab.
