# Mail

The Mail page of the [Preferences](settings.md) sets how messages are opened
and displayed, the tags you can put on them, and who may send you distant
messages.

## Layout

The page holds four groups: **Reading**, **Tags**, **Distant messages:** and
**Fonts**.

## Buttons

### Reading

- **Set message to read on activate**: a message is marked as read as soon as
  you select it in the list. When the box is not checked, a new message stays
  unread until you mark it yourself. On by default.
- **Load embedded images**: the images contained in a message are displayed
  when you open it. When the box is not checked, the images are blocked and
  you choose message by message to show them. Off by default.
- **Load Emoticons**: the text smileys of a message are shown as pictures.
- **Open messages in**: where a message opens when you double-click it in the
  list. A draft always opens in the window where you write a message.
  - **A new tab**: in a new tab of the Mail page. This is the default.
  - **A new window**: in a separate window.

### Tags

Tags are coloured labels used to categorize and prioritize your messages.
The list shows every tag in its colour. RetroShare comes with a few standard
tags; you can add your own.

- **Add**: opens the **New Tag** dialog.
- **Edit**: opens the same dialog, titled **Edit Tag**, for the selected tag.
- **Delete**: deletes the selected tag. Only the tags you created can be
  deleted; the button is greyed for a standard tag.
- **Default**: gives the standard tags their original names and colours
  back. Your own tags are not changed.

### Distant messages:

**Accept encrypted distant messages from** chooses who may send you a message
through the anonymous tunnels, that is from an identity that does not belong
to one of your connected friends:

- **Everyone**: any identity.
- **Contacts**: only the identities that are in your contacts.
- **Nobody**: distant messages are refused.

### Fonts

- **Minimum font size**: the size of the text in the window where you write a
  message. The list holds the standard sizes; the default is 11 (12 on
  macOS).

## Dialogs

### New Tag

- **Name:** the name of the tag. It must not be empty nor the name of
  another tag. The name of a standard tag cannot be changed.
- The colour button (tooltip **Choose color**) opens the colour chooser.
- **OK** saves the tag. It is greyed while the name is not valid.
- **Cancel** closes the dialog without change.

## How to

### Create a tag

1. Click **Add**.
2. Type a name and click the colour button to pick a colour.
3. Click **OK**. The tag is now offered in the tag menu of the
   [Mail](mail.md) page.
