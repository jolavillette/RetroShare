# Boards

This page of the preferences sets how the [Boards](boards.md) page opens the
boards you select.

Every change is applied at once.

## Layout

The page has a single group, **Tabs**.

## Buttons

- **Open each board in a new tab**: when checked, every board you select in the
  list opens in its own tab, and the tabs stay open until you close them. When
  unchecked, the Boards page shows one board at a time: selecting another
  board replaces the one on screen, and the extra tabs that were open are
  closed. Off by default. Whatever the choice, the entry **Open in new tab** of
  the context menu of the board list still opens a board in an additional tab.
- **Hide tabbar with one open tab**: when checked, the bar that holds the tabs
  is hidden as long as only one board is open. On by default.

## Related settings

- [Channels preferences](settings-channels.md): the option **Load Emoticons**
  of that page also decides whether smileys are drawn in the description of a
  board.
- [Notify](settings-notify.md): the entries **Boards** and **Board Post**
  choose how you are told about new posts.
